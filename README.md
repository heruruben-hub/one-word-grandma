# One Word From Grandma

Entry for the make.fun bounty [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

The word a grandma would text about AI:

> "robit"

The sweet misspelling she would actually type when she means "robot" —
warm, a little baffled, and unmistakably about a machine.

## Run

```sh
python3 main.py
```

This writes the single word to `/output/entry.txt`.
